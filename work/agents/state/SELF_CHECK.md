# SELF_CHECK — promises made to the owner in chat

A promise to the owner in chat («сделаю», «потом», «ночью», "I'll do it later/tonight") is a debt. **In the same turn it is made
it becomes a `TODO.md` row (then write `→ TODO <ROW-ID>` here) or a line below.** Check this page at EVERY handover and before
every acknowledgement of a Delivery: a line still open whose time has come is the next action. Close a line (`[x]`) only with
the evidence — the commit, the file or the sentence that kept the promise.

Line shape: `- [ ] <YYYY-MM-DD> «<what I promised, his words if he asked>» · due <when> · → TODO <ROW-ID> | owner: me`
